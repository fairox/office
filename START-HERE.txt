OFFICE CONFIGURATOR
===================

Lay out a single office room (desks along the walls or in back-to-back
benches, a meeting table, phone booths) in your browser, with a 3D view, a dimensioned plan and checks.

1. INSTALL
   You need Python 3.8 or newer. Nothing else.
   - Windows: https://www.python.org/downloads/windows/
     In the installer, tick "Add python.exe to PATH".
   - macOS:   https://www.python.org/downloads/macos/
   - Linux:   usually installed already; otherwise  sudo apt install python3

2. START
   - Windows: double-click  "Start Office Configurator.bat"
   - macOS:   double-click  "Start Office Configurator.command"
              (first time: right-click > Open, because it was downloaded)
   - Linux:   run  ./start.sh
   Your browser opens the configurator. Keep the small window that appears
   open while you work; close it (or press Ctrl+C in it) to stop.

3. USE
   - Pick a preset, then type the room size and openings in exact mm.
     Each opening is measured from a corner you choose; switching the corner
     converts the number and leaves the opening where it is.
   - Under Programme, choose how desks are arranged (along the walls,
     back-to-back benches, or walls first) and a rectangular or round table.
   - Press "Fix site" once the room matches your drawing. After that, presets
     and strategies only change the furniture, never the room or its openings.
   - The Checks list says what did not fit and by how much. Nothing is dropped
     without a message there.
   - Your work is saved in the browser and in the page address: copy the
     address to send someone exactly what you see.
   - Tier M (whole floor plates): choose "M" under Tier. Give the outline
     (or make one from a Rectangle / L / U / T shape), the doors and windows
     on its edges, the column grid and the core. Then ask for teams, rooms,
     booths. A primary aisle (the spine) is laid out, rooms line up along it,
     and team benches fill the rest. Pin a room to keep it exactly where you
     put it. "Furthest from an exit" shows the longest walk to an exit; set
     the limit your escape rules require (45 m is only a placeholder).

4. BUILD IN ARCHICAD
   You need Archicad with the Tapir add-on (1.7.x), and Python with Tkinter
   (the python.org installer includes it).
   - In the web app, press "Download build file".
   - Open the Build in Archicad window: in Tapir's script palette run
     archicad/OfficeBuild.py, or double-click "Build in Archicad.bat"
     (Windows) / "Build in Archicad.command" (macOS).
   - The newest build file in your Downloads folder is loaded by itself.
     Pick the project if several Archicads are open; nothing is guessed.
   - FIRST TIME: press "Test placement". It builds one sample of every kind,
     checks each one, and deletes them again. Building is unlocked only
     after it passes.
   - Press "Build in Archicad". Everything lands on OFFICE layers with an
     Element ID OF-<run>-<name>, and every element is checked afterwards.
   - Building again replaces the previous build, but only elements that are
     still exactly as built; anything you moved or changed is kept.
   - "From selected Zone": select a rectangular Zone in Archicad first; the
     window places the design there and "Open web app" designs for that room.
   - Every run is logged in Documents/Office Configurator/journal.

TROUBLESHOOTING
   - "Python was not found" / the Microsoft Store opens: Windows is using its
     placeholder alias. Install Python from python.org (step 1), or switch the
     alias off: Settings > Apps > Advanced app settings > App execution aliases.
   - The browser does not open: copy the address shown in the small window
     (http://127.0.0.1:8765/ or the next free port) into your browser.
   - The 3D view says it is unavailable: your browser has WebGL switched off.
     The plan and checks still work.
   - Start again from scratch: choose a preset with the site released.
   - "Several Archicads are open": pick the project in the window's Project
     list. The window never chooses for you.
   - "Run Test placement first": this Tapir version has not been tested on
     this computer yet. Test placement builds and deletes a few samples.
   - A build stopped half way: choose "Remove run ... only" and that run.
     Only elements still exactly as built are deleted.
